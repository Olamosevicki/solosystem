# ⚡ THE SYSTEM — Solo Leveling Bot

A personal productivity bot built on the Solo Leveling RPG system.

## Setup
1. Set environment variables in Railway:
   - `BOT_TOKEN` — your Telegram bot token
   - `USER_ID` — your Telegram user ID

2. Deploy as a Worker (not Web Service)

## Commands
- /start — Boot up the System
- /status — Full stats dashboard  
- /quests — Today's quest log with completion buttons
- /done [quest name] — Complete a quest
- /penalty — View penalty quests
- /help — All commands
